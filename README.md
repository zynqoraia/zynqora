# Zynqora

Zynqora es un sistema de inteligencia personal diseñado para capturar, comprender, organizar y recuperar información utilizando inteligencia artificial.

## Objetivo

Permitir que una persona pueda guardar información de diferentes formas:

- Fotografías
- Documentos
- PDF
- Texto
- Notas
- Voz
- Compras
- Facturas
- Tareas
- Eventos
- Ideas

Zynqora utiliza inteligencia artificial para comprender esta información y organizarla automáticamente.

## Arquitectura

Zynqora está compuesto inicialmente por:

- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: PostgreSQL mediante Supabase
- Storage: Supabase Storage
- Autenticación: Supabase Auth
- Inteligencia artificial: API multimodal de IA
